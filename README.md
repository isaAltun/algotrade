# AlgoTrade

*Ett handelssystem som är byggt för att kunna dö.*

CV-sida om AlgoTrade, ett automatiserat handelssystem i Python med maskininlärning och statistisk självkontroll.

Siffrorna på sidan är en ögonblicksbild per 18 okt 2026. Repot innehåller bara sidan. Källkoden till själva systemet är privat.
